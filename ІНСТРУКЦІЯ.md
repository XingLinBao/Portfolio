# Інструкція: налаштування й публікація сайту-портфоліо

## 1. Проєкт у Firebase
1. Відкрийте https://console.firebase.google.com → **Add project** (Google Analytics можна вимкнути). Тариф Spark безкоштовний, картка не потрібна.
2. У проєкті: **Project settings → Your apps → Web (</>)** → зареєструйте застосунок і скопіюйте об’єкт `firebaseConfig`.

## 2. Authentication
1. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable**.
2. Вкладка **Users → Add user**: введіть свій email і пароль. Скопіюйте **User UID** цього користувача.
3. **Settings → Authorized domains**: залиште лише домен, де буде сайт (і localhost для перевірки).

## 3. Firestore
1. **Build → Firestore Database → Create database** (режим production, найближчий регіон, напр. `eur3`).
2. Вкладка **Rules**: вставте вміст `firestore.rules`, замініть `ВСТАВТЕ_UID` на свій UID, натисніть **Publish**.
Cloud Storage не потрібен.

## 4. Конфігурація
Відкрийте `js/config.js`, вставте значення `firebaseConfig` та свій UID у `OWNER_UID`.

## 5. Публікація
Сайт використовує ES-модулі, тому **не відкривається подвійним кліком із диска** — потрібен http(s)-сервер.
- **Firebase Hosting:** `npm i -g firebase-tools` → `firebase login` → `firebase init hosting` (public directory — папка сайту, SPA — ні) → `firebase deploy`.
- Або будь-який статичний хостинг (GitHub Pages, Netlify). Для перевірки локально: `python -m http.server` у папці сайту й адреса http://localhost:8000.
Публічна сторінка — `index.html`, кабінет — `admin.html` (посилання на нього на сайті немає; збережіть закладку).

## 6. Перший вхід
Відкрийте `admin.html`, увійдіть. Автоматично запуститься **майстер налаштування** (7 кроків, прогрес зберігається). Пізніше його можна запустити кнопкою «Майстер налаштування».

## 7. Посилання на документи в Google Диску
Правий клік на файлі → **Поділитися → Доступ для всіх, хто має посилання → роль «Читач»** → скопіюйте посилання й вставте в поле «Посилання» (лише https://). Кнопка «Перевірити посилання» відкриє його в новій вкладці.

## 8. Фото
До 6 фото на запис, jpg/png/webp. Вони автоматично зменшуються й зберігаються в самому документі (ліміт Firestore — 1 МБ). Якщо з’являється повідомлення про завеликий розмір — зменште кількість фото.

## 9. Резервна копія і пароль
- **Копія:** експорт Firestore потребує тарифу Blaze; на Spark можна періодично зберігати скриншоти/копії важливих текстів та оригінали фото в себе.
- **Забули пароль:** на сторінці входу натисніть «Забули пароль?» — лист надійде на email. Або змініть пароль у консолі: Authentication → Users → ⋮ → Reset password.
