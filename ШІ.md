# ШІ (Google Gemini) в інтерактивних завданнях

## Що це дає
У кабінеті (`admin.html`) з’явилися дві кнопки:

- **Інтерактивні заняття → Тест → «Тест від ШІ»** — задаєте тему (HTML/CSS/JS), рівень, типи й кількість запитань. ШІ складає їх, ви переглядаєте й додаєте потрібні.
- **Практика → «Додати тему» → «Створити завдання з ШІ»** — ШІ створює завдання: умову, початковий код, підказку, еталонний розв’язок і правила перевірки. **Кожен розв’язок автоматично проганяється через ваш валідатор**; якщо не проходить — ШІ отримує помилку й виправляє завдання один раз. У перегляді видно, які завдання працюють (їх позначено галочкою), а які краще доопрацювати.

Нічого не публікується автоматично: згенероване потрапляє у форму, і лише ваше «Зберегти» записує його в Firestore. Правила `firestore.rules` змінювати не потрібно.

## Крок 1. Отримайте безкоштовний ключ Gemini
1. Відкрийте **https://aistudio.google.com/apikey** і увійдіть своїм Google-акаунтом.
2. Натисніть **Create API key** (за потреби оберіть або створіть проєкт — підійде будь-який).
3. Скопіюйте ключ (починається з `AIza…`). Банківська картка не потрібна.
4. Свої ліміти бачите на **https://aistudio.google.com/rate-limit** — вони залежать від моделі й можуть змінюватися.

> Не публікуйте ключ на GitHub і нікому його не надсилайте. Якщо ключ потрапив у відкритий доступ — видаліть його в AI Studio й створіть новий.

## Крок 2. Підключіть ключ — оберіть один спосіб

### Спосіб А — швидкий старт (1 хвилина)
1. Відкрийте `admin.html`, увійдіть.
2. Натисніть «Тест від ШІ» (на вкладці «Інтерактивні заняття → Тест»).
3. Вставте ключ у поле «Ключ Gemini API». Він збережеться **лише в цьому браузері**.

Просто й безкоштовно. Мінус: ключ лежить у браузері, і на кожному новому пристрої його треба вводити знову. Для безкоштовного ключа це прийнятний ризик: найгірше, що станеться, — вичерпається ліміт.

### Спосіб Б — ключ на сервері (рекомендовано, також безкоштовно)
1. Зареєструйтесь на **https://dash.cloudflare.com** → **Workers & Pages → Create → Create Worker** → назвіть, наприклад, `portfolio-ai` → Deploy.
2. Натисніть **Edit code**, видаліть усе й вставте вміст файлу `worker/ai-proxy.js` → **Deploy**.
3. У воркері: **Settings → Variables and Secrets → Add** (чотири змінні):
   | Назва | Тип | Значення |
   |---|---|---|
   | `GEMINI_KEY` | Secret | ваш ключ Gemini |
   | `PROJECT_ID` | Text | `portfolio-55d2e` (з `js/config.js`) |
   | `OWNER_UID` | Text | значення `OWNER_UID` з `js/config.js` |
   | `ALLOWED_ORIGIN` | Text | адреса вашого сайту без слеша в кінці, напр. `https://login.github.io` |
4. Скопіюйте адресу воркера (на кшталт `https://portfolio-ai.ваш-логін.workers.dev`) і вставте в `js/config.js`:
   ```js
   export const AI_PROXY_URL = "https://portfolio-ai.ваш-логін.workers.dev";
   ```
5. Опублікуйте оновлений сайт. Поле для ключа в кабінеті зникне — ключ тепер на сервері.

Воркер приймає запити лише з вашого сайту й лише з токеном вашого облікового запису, тож ніхто інший не зможе витрачати ваш ліміт.

## Крок 3. Користуйтеся
**Тест:** «Тест від ШІ» → тема, рівень, кількість → «Згенерувати» → зніміть позначки з зайвих → «Додати вибрані». Запитання можна відредагувати як звичайні.

**Практика:** «Додати тему» → «Створити завдання з ШІ» → тема (чим конкретніша, тим краще: «Списки ul/ol: вкладені списки», а не просто «HTML»), мова, рівень, кількість → «Згенерувати». Зачекайте 1–2 хвилини: іде перевірка кожного розв’язку. Додайте вибрані завдання й натисніть **«Зберегти» у вікні теми**.

## Модель і ліміти
Модель задається в `js/config.js` → `AI_MODEL` (за замовчуванням `gemini-3.8-flash`).

- Якщо часто з’являється «Вичерпано ліміт» — спробуйте `gemini-3.5-flash-lite` (зазвичай щедріші ліміти, трохи слабша якість).
- Назви моделей Google змінює часто. Якщо отримуєте «Модель недоступна» — відкрийте https://ai.google.dev/gemini-api/docs/models, візьміть актуальну назву й вставте в `AI_MODEL`. Для способу Б додайте її ще й у масив `MODELS` у `worker/ai-proxy.js`.
- Безкоштовний тариф має ліміт запитів на хвилину й на добу. Генерація завдань робить кілька запитів (основний + виправлення), тому створюйте по 2–4 завдання за раз. Якщо ліміт хвилинний, програма сама зачекає й повторить запит.

## Конфіденційність
За умовами Google, на безкоштовному тарифі запити можуть використовуватись для покращення їхніх продуктів. Тому не вставляйте у тему персональні дані студентів — для завдань з HTML/CSS/JS вони й не потрібні.

## Якщо щось не працює
| Повідомлення | Що робити |
|---|---|
| «Ключ Gemini API недійсний» | Створіть ключ заново на aistudio.google.com/apikey й вставте ще раз |
| «Вичерпано ліміт безкоштовного тарифу» | Зачекайте хвилину (або до завтра, якщо добовий ліміт), змініть модель на `…flash-lite` |
| «Модель недоступна» | Оновіть `AI_MODEL` (див. вище) |
| «Сервери Gemini перевантажені» | Повторіть за кілька хвилин |
| «Немає доступу» (спосіб Б) | Перевірте `OWNER_UID`, `PROJECT_ID` і що ви увійшли в кабінет |
| Помилка CORS у консолі браузера (спосіб Б) | `ALLOWED_ORIGIN` має точно збігатися з адресою сайту, без слеша в кінці |

## Поради щодо якості
- Завжди читайте згенероване: ШІ може помилитись у фактах. Валідатор перевіряє, що розв’язок працює, але не те, що умова добре сформульована.
- Безкоштовні моделі слабші за платні. Завдання, позначені попередженням, зазвичай легко виправити вручну.
